# SSAC 2027 abstract: the submission package

SOP step W6.12. Everything here except the confirmation and the receipt is generated by
`make abstract` (`scripts/abstract.sh`) from `docs/numbers.json`. Do not edit a generated
file by hand. Change the template or the ledger and rebuild.

## Deadline

The conference page says "Oct. 1, 2026 11:59 p.m. EST".

- Read as eastern daylight time (UTC-4), which the eastern United States is on that day,
  it is **05:59 Madrid on 2026-10-02**.
- Read literally as EST (UTC-5), it is 06:59 Madrid on 2026-10-02.
- The project works to the earlier reading, 05:59 Madrid.
- The target is **12:00 Madrid on 2026-10-01**, a full clock day before the earlier reading.

## What is here

| file | written by | what it is |
|---|---|---|
| `submitted-abstract.txt` | `tools/comms/build_submission.py` | title and body, for a form with an upload field |
| `submitted-abstract.inline-table.txt` | the same | the body with Table 1 inline, for a form with none |
| `paste-sheet.md` | the same | field by field, in form order, with word counts |
| `R1-agenda.md` | `tools/comms/r1_agenda.py` | the owner's review R1 |
| `freeze.json` | `ops/coldbuild.sh --freeze` | the frozen commit and the ledger's sha256 |

`quality/w612_check.sh` checks the package: the SOP word counter at 470, no unfilled slot,
the blind-review grep, the four sections, and the writing gates.

## The submit is the owner's

The form is sign-in gated. An unauthenticated fetch returns HTTP 401, so no agent can
submit. Author fields go in the form only, never in the body. They are listed in
`abstract/FORM-FIELDS.md`, section 3 item 7, and are not copied here.

## After submitting

1. Screenshot the confirmation page to
   `submissions/ssac2027/confirmation-$(TZ=Europe/Madrid date +%Y%m%dT%H%M%S).png`.
2. Save the Google Forms receipt email as `submissions/ssac2027/receipt.eml`.
3. Keep `submitted-abstract.txt` byte for byte as pasted. If the pasted body was the
   inline-table copy, copy that file over `submitted-abstract.txt` first.
4. Re-run fleet phase 06. Its archive step commits the three files, tags
   `ssac2027-abstract-submitted` and pushes.
